# SSL/TLS Certificates

This directory contains self-signed SSL certificates for DogParkPals services.

## Certificate Files

### Application Services
- `server.crt` / `server.key` - Backend API server (Node.js/Express)

### Observability Services
- `prometheus.crt` / `prometheus.key` - Prometheus metrics server
- `grafana.crt` / `grafana.key` - Grafana dashboards
- `elasticsearch.crt` / `elasticsearch.key` - Elasticsearch search/logging
- `kibana.crt` / `kibana.key` - Kibana log visualization
- `rabbitmq.crt` / `rabbitmq.key` - RabbitMQ management interface

## Generation

These certificates are automatically generated by the setup scripts. To regenerate manually:

```bash
# For each service:
openssl req -x509 -newkey rsa:2048 -keyout SERVICE.key -out SERVICE.crt -days 365 -nodes -subj "/CN=SERVICE/O=DogParkPals/C=US"
```

Replace `SERVICE` with: server, prometheus, grafana, elasticsearch, kibana, or rabbitmq.

## Security Notes

- **Development Only**: These are self-signed certificates for local development
- **Production**: Replace with properly signed certificates from a Certificate Authority (e.g., Let's Encrypt)
- **Validity**: 365 days from generation date
- **Gitignored**: All certificate files are excluded from version control for security

## File Permissions

- `.crt` files: 644 (readable by all)
- `.key` files: 600 (readable only by owner) - private keys must be protected

## Docker Usage

Certificates are mounted as read-only volumes in docker-compose.yml:
```yaml
volumes:
  - ./certs:/app/certs:ro
```
